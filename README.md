# Project B: Randall's plaque transcriptomic comparator analysis

Public analysis-source package version 1.1 (9 October 2026), for GSE73680 and GSE117518.
It contains 38 frozen source CSVs, retained processed inputs, plotting inputs, portable code,
vector figures and verification records for an author-review manuscript.

## Download

Download all four archives and extract them into the same empty directory.
Run `python code/verify_files.py`, then follow the extracted README for dependencies and replay instructions.

## Verification and changes

All 2,800 metrics from the 200 fixed saved allocations matched exactly; all 48 aggregate descriptors
agreed within 1e-10. Three primary internal models previously reproduced every coefficient and
moderated t statistic. The version 1.1 figure entry point reproduces all nine supplied figures
pixel-for-pixel. Figures 1, 4 and 5 clarify annotation scope and legends; statistical results and
the selected palette are unchanged. Derived-field definitions and complete replay records are included.

The 500 stored label-flip outputs were not rerun. Their descriptive tail fractions are not calibrated
P values. Split distributions are dependent and external agreement is selective. The retained data
do not establish biological antagonism, global replication or validated targets. An original external
fit was unavailable; sequence alignment was not rerun.
